Install MyEditor Update MyEditor

MyEditor is free and open source. It isn't registered with Apple or Microsoft yet, so your computer asks you to confirm it the first time. These steps show exactly what to click.

Updating takes the same steps as installing. Your settings and documents stay where they are.

Something looks different?
macOS says MyEditor is damaged and can't be opened

This can happen when a download breaks on the way. Download MyEditor again first. If the message stays, open the Terminal app, paste this line, and press Return:

xattr -dr com.apple.quarantine "/Applications/MyEditor.app"
There's no Open Anyway button

The button appears only for about an hour after you try to open MyEditor. Open MyEditor from Applications again, click Done, then go back to Privacy & Security.

My Mac runs macOS 14 Sonoma or older

Right-click MyEditor in Applications, choose Open, then click Open in the message.

I opened MyEditor from the disk image window

Quit it, drag MyEditor onto Applications, and open it from there. A copy opened from the disk image stops working once the disk is ejected.

Something looks different?
Smart App Control has blocked this app

Smart App Control doesn't allow exceptions for single apps. To install MyEditor, turn it off in Windows Security > App & browser control > Smart App Control settings. Recent Windows updates let you turn it back on later without reinstalling Windows.

There's no Run anyway button

Click More info first. Run anyway only appears after that.

My antivirus removed the file

Some antivirus tools flag new apps from small developers by mistake. Restore the file from quarantine, or download it again and compare its checksum with the one under Verify your download.

Windows says the installer can't run on this PC

MyEditor needs 64-bit Windows 10 or Windows 11.

MyEditor for Linux

  1. Choose your download

    Pick the kind of Linux you use. Both are for 64-bit Intel and AMD processors (x86_64).

    Ubuntu, Debian, Linux Mint, or Pop!_OS A .deb package. Installs like any other app, with a menu entry. Download .deb
    Any other distribution An AppImage. One file that runs without installing. Download AppImage

  2. Install it with App CenterInstall the new package

    Double-click the downloaded file. App Center opens and warns that the package comes from outside its catalog. Click Install and enter your password.

    Quit MyEditor, then double-click the downloaded file and click Install. It replaces the old version.

    No App Center, or the file opens in an archive viewer? Run this in a terminal, in your Downloads folder:

    sudo apt install ./my-editor_*_amd64.deb
    App Center✕

  3. Allow it to run

    Right-click the downloaded file and choose Properties. Turn on Executable as Program, then double-click the file.

    Quit MyEditor. Put the new file where the old one was, turn on Executable as Program in its Properties, then double-click it.

    Prefer the terminal? This does the same:

    Open MyEditor from your applications menu. To remove it later, run sudo apt remove my-editor.

    Double-click the AppImage to open MyEditor. The file is the whole app, so keep it somewhere handy, like a folder in your home directory. To add it to your app menu, use AppImageLauncher.

    Open MyEditor again. It starts on the new version.

Something looks different?
The AppImage doesn't start

Install one missing library, then try again. On Ubuntu, Debian and Mint:

sudo apt install libxcb-cursor0

On Fedora:

sudo dnf install xcb-util-cursor
Double-clicking the .deb opens an archive viewer

Your desktop has no package installer. Use the terminal command from the install step.

My computer has an ARM processor, like a Raspberry Pi

There's no ARM build yet. You can run MyEditor from source.
