# MyEditor v3.3

## Highlights

- **Built-in PDF reader** - open PDFs in a clean, read-only tab with search, a contents sidebar, text copy, working links and SumatraPDF-style keys, and every file reopens at the page you left. F11 now goes full screen anywhere in the app.
- **Universal importer** - bring in posts from any blog or feed, Nostr profiles and articles, Bluesky threads, Markdown files, GitHub folders, sitemaps, and WordPress, Ghost, Medium, Substack or OPML exports, all saved as private, encrypted drafts.
- **Look before you import** - every source opens as a checklist with dates and read times, you pick the newest 10, 25, 50, all, or only what is new, and nothing is signed until you press Import. Teaser-only feeds arrive as full articles, podcasts as episodes with chapters, and images move to your own media server.
- **Step-by-step install guide** - a new install page picks the right download for your computer and walks you through every macOS, Windows and Linux security prompt, with a picture of each dialog and the button to press.
- **Guided updates** - Software Update installs new versions in place on Windows and the AppImage, and walks macOS and `.deb` users through the same steps as installing.
- **Print** - File > Print (`Cmd+P` / `Ctrl+P`) prints the current note or PDF with the same layout as the PDF export. Windows and Linux also get Print Preview.
- **Pictures are never lost** - images you paste or insert are kept on your computer first and uploaded afterwards, so going offline, a failed upload or a crash no longer loses them, and any save that would drop an image warns you first.
- **Private media stays private** - your encrypted private pictures (compatible with Lotus) show in the media library, and using one in a public post asks first, then makes a separate public copy with camera and location data removed.
- **Self-contained HTML and PDF export** - exported HTML carries its images inside the file, and PDFs get page setup, page numbers and document details.
- **R Markdown support** - open, edit and knit `.Rmd` files to HTML or PDF, or convert any document to R Markdown. If R, pandoc or the other tools are missing, the app offers to install them from their official sources.
- **A calmer drafts panel** - hover over a draft or press Space for a preview, search looks inside the text, titles no longer show raw Markdown, and you can select many drafts and delete them at once.
- **Signers that just work** - pairing works with more signer apps, saved sessions reconnect reliably, and when your signer stops answering the app says so instead of waiting forever.
- **Dialogs that read right everywhere** - every alert now looks the same on macOS, Windows and Linux, with clear buttons like Save, Don't Save and Cancel. The unreadable Move to Trash button on Linux is fixed.
- **Einundzwanzig members** - members are recognised automatically, their notes and articles also go to the members' relay, and the members' media server is added next to their own.
- **Writing-first default** - syntax highlighting now starts off, like line numbers. `Ctrl+Shift+H` turns it on.

## Technical updates & fixes

- New dependency: `readability-lxml`, for full-text recovery of teaser-only feeds.
- The macOS install steps now match macOS 15 and later: Open Anyway in Privacy & Security replaces right-click > Open, which Apple removed.
- One shared alert (`alerts.py`) replaces every `QMessageBox`, with each platform's own button order (closes #37). Quitting with unsaved work asks once instead of twice.
- Printing and PDF export share one pagination path, so a printed page matches the exported page.
- `release_assets.py` gives the updater and the install guide one naming rule for installers. The updater now recognises `.deb` installs.
- CI checks the macOS bundle's seal with `codesign --verify --deep --strict`, and each release redeploys the install guide to GitHub Pages.
- Releases no longer ship `appimagetool` as a stray download.
- Packaging bundles QtPdf and registers MyEditor as an optional PDF viewer on macOS, Windows and Linux.
- PDF link hit-testing and text selection follow a test-pinned copy of QPdfView's layout math, which fixes links that stopped working after scrolling.
- HTML export writes semantic HTML5 (real lists, inline colors, embedded images) instead of Qt's `toHtml()` output.
- The importer is a resolver registry in `nostr/imports/`: breadth-first feed discovery, parsing off the UI thread, oversized bodies aborted mid-transfer, and stable error codes. Subscriptions sync as one NIP-44 encrypted kind 30078 event.
- New local-first asset store in `nostr/media/` with an upload state machine that can always retry. Published notes no longer carry an invisible U+FFFC where an image was.
- Security: auth headers and upload bodies never follow redirects, server-returned URLs are checked before they are stored, one URL guard covers every handoff to the OS, image decoding uses a format allowlist (no SVG reads of local files), and exports never embed local files a document only names.
- Blossom BUD-11/12 compliance: base64url auth, the `x` tag on mirror, hashes verified against the bytes sent, and cursor pagination. Uploads replicate to the remaining servers one at a time, and importer images use the shared upload path.
- NIP-46: spec connect responses and `auth_url` challenges, undecryptable payloads reported, ping falls back to `get_public_key`, and a 6 s timeout.
- Private media: Lotus-compatible encryption, private and public blobs as separate types, public copies re-encoded without EXIF or GPS data, and keys held in memory only.
- Media library: Lotus drive folders no longer block publishing, files still being checked no longer show as NOT CHECKED, and thumbnails say why a preview is missing.
