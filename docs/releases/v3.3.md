# MyEditor v3.3 (draft)

## Highlights

- **A universal importer** - the Feeds page of the drafts panel now imports
  from far more than RSS. Paste a blog URL, an `npub`, a Bluesky thread link,
  a Markdown file or GitHub folder URL, or a sitemap; upload a WordPress (WXR)
  or Ghost export, a Medium / Substack ZIP, or an OPML subscription list. The
  importer figures out which it is and everything lands in the same place:
  private, encrypted NIP-37 drafts.
- **Preview before anything is signed** - loading a source now shows a
  checklist of its items with dates and read times. Pick a scope (newest 10 /
  25 / 50 / all / new since last import), untick what you don't want, then
  import. No more blind batch imports.
- **Full-text recovery** - teaser-only feeds (Webflow, Squarespace, some
  WordPress / Ghost configs) get their article pages fetched and the real
  body extracted, so drafts carry the article, not the blurb.
- **Images move with you** - images in imported posts are mirrored to your
  Blossom server (the server fetches them itself) and the draft rewritten to
  the mirrored URLs, so drafts don't depend on the source site staying up. A
  review dialog lets you keep chosen images at their original URLs.
- **Podcast feeds import as episodes** - audio link, duration, chapter list
  with timestamps, transcript link, then the show notes.
- **Feed subscriptions that follow you** - subscribed sources are stored as a
  single encrypted event on your relays, so they sync across devices without
  leaking your reading list. Imports stamp a "last imported" time that powers
  the "new since last import" scope.
- **Imported drafts are labeled** - rows in the drafts list show an
  "Imported" badge with the origin feed or file in the tooltip.

## Technical updates & fixes

- New `nostr/imports/` package: a source-resolver registry (detect + resolve
  per source kind) feeding one normalised `Feed` shape into a preview filter
  and a sequential import pipeline. Adding a source format is one resolver
  module, one registry entry, and tests.
- Feed discovery upgraded to a breadth-first search: every
  `<link rel="alternate">` hint, then a common-path palette probed under the
  pasted path, its first segment, and the origin, then the site's sitemap
  (via robots.txt) as the final fallback.
- Long-form (naddr) recovery now triggers on any addressable coordinate
  (bech32 anywhere in the link/guid, or a bare NIP-01 `kind:pubkey:d` in the
  guid) and keeps whichever body is longer.
- Newly imported drafts carry an `rss-` d-tag prefix; drafts imported before
  this release are grandfathered (re-imports reuse the old identifier instead
  of duplicating).
- Feed parsing and HTML-to-Markdown conversion moved off the UI thread; the
  fetcher aborts oversized bodies mid-transfer instead of buffering them.
- A stable error-code taxonomy with friendly copy replaces ad-hoc error
  strings across the importer.
- New dependency: `readability-lxml` (full-text recovery).
