# Keyboard shortcuts

The keys follow each system's own habits: Apple Notes and Pages on a Mac, Google Docs and LibreOffice on Windows and Linux. A command no app has a key for has none here either. **Help > Keyboard Shortcuts** (**⌘/** / **Ctrl+/**) shows the same list in the app, with your keyboard's own key names, and lets you search it.

A dash (–) means the command is in the menu but has no key on that system.
